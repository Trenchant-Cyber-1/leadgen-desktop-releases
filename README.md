# LeadGen Desktop — releases

Installers and the auto-update feed for **LeadGen Desktop**. This repository contains no source code.

## Download

Open the [latest release](../../releases/latest) and pick your platform:

| Platform | File |
|---|---|
| Windows | `LeadGen.Desktop_<version>_x64-setup.exe` |
| Debian / Ubuntu | `LeadGen.Desktop_<version>_amd64.deb` |
| Fedora / RHEL | `LeadGen.Desktop-<version>-1.x86_64.rpm` |

Installers are not code-signed, so Windows SmartScreen may ask you to confirm ("More info" → "Run anyway").

## Updates

Installed Windows copies check for updates on startup and ask before installing. You can also use **Help → Check for Updates…**. Updates install over the current version and keep your data. Linux packages are updated by installing the new `.deb`/`.rpm`.
